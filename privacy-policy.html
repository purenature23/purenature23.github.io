Privacy Policy

Last updated: [08.08.2026]

This application is a personal, self-hosted content automation tool. It is used solely to generate and publish short-form video content to my own TikTok account.

What this app does: This app connects to TikTok's Content Posting API using TikTok's official Login Kit (OAuth 2.0) to authorize posting videos directly to my own TikTok account on my behalf. It does not access, store, or process data belonging to any other TikTok user.

Data collected: The only data this app handles is:

  • My own TikTok access token and refresh token, used solely to authorize video uploads to my own account
  • Basic profile information (open ID, display name) returned by TikTok's user.info.basic scope, used only to confirm which account is authorized

This data is stored locally on my own device and is never shared with, sold to, or transmitted to any third party.

Data retention: Authorization tokens are stored locally until manually revoked or replaced. No other user data is retained.
